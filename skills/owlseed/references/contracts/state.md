# 契約: owlseed-state

## 役割

現在地と復帰の保証。L2（状態）の所有者。「今どこにいるか」「何が決まっていて何が待っているか」「壊れたらどう戻すか」に答える。

## 保証すべきこと

- 現在進行中の作業単位、待っている作業単位、終わった作業単位を答えられる
- 作業単位ごとの状態（未着手・進行中・検証済み・差し戻し）と根拠への参照を保持する
- 決定履歴（目的・範囲・検証契約の変更、受入ゲートの判定理由、上位下位の矛盾）を保持する
- 沈殿待ちの改善を保持する
- 復帰可能な状態の定義と、壊れた時の戻し方を答えられる
- L2の所在と形式を所有し、他のSkillに答えられる
- 記録しているowlseedの版を答えられる
- owlseedが読まれていなければ、まずowlseedを読ませる

## 禁止

- 未記録の作業途中を残したまま収束させる
- 作業単位の一覧から項目を削除・改変して履歴を失わせる（状態の更新はよい）

## 参照される段階

定位・選択・実行・沈殿・収束。ほぼ毎回。

## descriptionの雛形

```
<プロジェクト名>の現在の作業状態・作業単位の一覧・決定履歴・復旧手順を保持する。作業を再開する時、進捗を確認する時、今何をすべきか迷う時、前回どこまで進んだか知りたい時、壊れた状態から戻す時に使う。owlseed配下。
```

## プロジェクトが埋めること

- L2の所在と形式（形式は自由。`guidance.md` に推奨がある）
- 作業単位の一覧の構造
- 決定履歴の構造
- 復帰可能な状態の定義（例: すべて記録済み、区切りが残っている、基本確認が通る）
- 復旧手順（バージョン管理での戻し方、初期化スクリプトなど）
- owlseedの版

## 生成時の注意

作業単位の一覧は、AIが勝手に書き換えにくい形式にすると安全性が上がる（`guidance.md`）。状態の更新は収束まで待たず逐次行う設計にする。
