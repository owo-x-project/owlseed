# 契約: owlseed-compass

## 役割

目的と範囲の番人。「この作業は何のためか」「どこまでが範囲か」「何をもって完了か」「何を人間に返すか」に答える。

## 保証すべきこと

- 与えられた作業単位が、プロジェクトの目的・範囲に沿っているかを答えられる
- 作業単位ごとに、何をもって完了とするかを答えられる
- 「この判断は人間に返す」という境界を答えられる（範囲の変更、破壊的操作、目的の解釈、外部への影響など）
- 目的・範囲が変わった時、それを決定として `owlseed-state` に記録させられる
- owlseedが読まれていなければ、まずowlseedを読ませる

## 禁止

- 目的・範囲の変更を、決定として記録せずに行う
- 判断権限の境界を超える判断を自律で行う

## 参照される段階

発芽（目的の確定）、定位（owlseed版と目的の整合確認）、選択（範囲判定）、実行（範囲変更の要否判断）。

## descriptionの雛形

```
<プロジェクト名>の目的・範囲・完了定義と、人間に確認すべき判断の境界を保持する。作業の妥当性を判断する時、依頼が範囲内か迷う時、完了かどうか判断する時、破壊的な操作や目的の解釈が必要な時に使う。owlseed配下。
```

## プロジェクトが埋めること

- 目的（一文で言えるもの、と、それを支える詳細）
- 範囲に含むもの・含まないもの
- 完了定義（作業単位の種類ごとに異なってよい）
- 判断権限の境界（人間に返すものの一覧、自律で決めてよいものの一覧）
- 目的・範囲の変更履歴への参照（本体は `owlseed-state`）

## 生成時の注意

目的が読み取れなければ、推測で埋めずに人間へ確認する。判断権限の境界は最初は保守的に（人間に返すものを多めに）設定し、経験で緩めてよい。緩める変更は受入ゲートを通す。
