# Germinate and rebuild

Do this when a core skill is missing. A core skill that was renamed, combined or split also counts as missing. Do it only when a human is there to answer.

1. Copy the matching template from assets to the place where the project keeps its skills. Do not change the name or the headings.
2. Look for material. A skill that has the core note at the top is an old core skill; use it as material. A document without the note gives only its content.
3. Fill in every part in angle brackets. Keep the lines above them; they say what owlseed asks under that heading. Go in this order: first where the records are, in owlseed-state, so that agreements can be recorded at once; then owlseed-compass from top to bottom; then owlseed-verify, using the same kind names as owlseed-compass; then the rest of owlseed-state. Take one heading at a time. Fill in from the project what the project can tell you: where the records go, the basic check, the ways to check. Ask a human for what only a human knows: the purpose, what is out of scope, what a human must decide, which kinds of work there are, and how each kind should go. Show the human what you guessed, and let them correct it. Do not move to the next heading until the human agrees. Write one line per answer when you can. Write the answers in the language the project uses. Keep the headings and the lines owlseed wrote in English, as they are in the template. Make sure no angle brackets remain.
4. Check gate conditions 3 and 7 only. Condition 3: every heading of the template is present and filled in, and the lines that say what owlseed asks are still there. Condition 7: keep the old skill until the new one fills every heading, and only then delete it. The other conditions in references/gate.md do not apply here.
5. As soon as a human agrees to a core skill, record the agreement as a decision in owlseed-state. Record the owlseed version there too.

Germination may end without a way of checking. Then write "not defined" in owlseed-verify. Orient will make a repair unit for it before any other work.

If the project has notes for agents, read them as material for understanding the project. If the notes also hold rules, procedures or records, leave them there for now, and add them to the improvement list in owlseed-state.
