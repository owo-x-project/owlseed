# 版と移行

## 版番号

owlseedはセマンティックバージョンを持つ。

- **メジャー** — 契約の名前変更・統合・分割。ライフサイクルの段階の追加・削除。受入ゲート条件の変更
- **マイナー** — 契約の保証の追加、references/の追加
- **パッチ** — 文言の修正、guidance.mdの更新

名前変更はプロジェクト側に再構成を強いるため、稀にする。契約の安定を優先する。

## プロジェクト側が記録する版

`owlseed-state` がプロジェクトに導入されたowlseedの版を記録する。定位でowlseedの版と比較し、異なれば本ファイルに従う。

## 移行手順

1. 版差分に対応する対応表（下記）を読む
2. パッチ・マイナー差分なら、`owlseed-state` の記録を更新するだけでよい。新しい保証が追加されていれば、該当コアSkillの改善候補として沈殿待ちに積む
3. メジャー差分なら、対応表に従って `owlseed-grow` が既存Skillから新Skillを再構成する
4. 再構成は受入ゲートを通す。特に条件3（新Skillが契約の保証を満たす）を確認する
5. 旧Skillは、新Skillが保証を満たすことを確認するまで削除せず退避する
6. `owlseed-state` の記録を更新する

再構成はLLM操作であり非決定的である。契約の「保証すべきこと」を確認項目として使い、満たせない項目があれば旧Skillを残したまま人間に返す。

## 対応表

| 旧版 → 新版 | 旧名 | 新名 | 種別 | 補足 |
|---|---|---|---|---|
| （初版のため対応なし） | | | | |

種別は 改名 / 統合（複数→1） / 分割（1→複数） / 廃止 / 新設。
